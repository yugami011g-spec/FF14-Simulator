# 時間軸・GCD最小実装

## 決定事項

- 経過時間、GCD再使用可能時刻、アクション硬直終了時刻、個別クールダウンを共有状態で管理する。
- 既定のアニメーション硬直は0.67秒、既存ウェポンスキルのGCDは2.5秒とする。
- 「次まで待機」は、現在時刻より後にある最も近い再使用可能時刻へ進める。
- 既存スキルがすべてGCDの場合、硬直終了だけで止まらず、1回の待機でGCD終了まで進める。
- 従来の履歴ログは、使用時刻を表示するタイムラインへ置き換える。

## 検証結果

- JavaScript 4ファイルの構文検査: 成功。
- 1段目使用 → 硬直終了まで待機 → GCD終了まで待機 → 2段目使用の自動テスト: 成功。
- コンボ時の合計威力500、使用時刻0.00秒/2.50秒、リセットを確認。
- `git diff --check`: エラーなし（改行コード警告のみ）。
- ブラウザによるローカルファイル表示はアクセス制約で実施できず。デスクトップ/モバイルの視覚確認は未実施。
